CSS Positions

This section demonstrates the 5 main types of positioning in CSS.

1. Static (Default)

Elements appear in the normal document flow. top, right, bottom, and left properties have no effect.

Static Box

2. Relative

Positioned relative to its normal (static) position. Other elements are not affected (it leaves a "ghost" space where it normally would be).

Relative Box (moved down & right)

3. Absolute

Positioned relative to its closest positioned ancestor (in this case, the gray container). Removed from normal document flow.

Absolute Box (top right)

4. Fixed

Positioned relative to the viewport (the browser window). It stays in place even when you scroll. (Look at the bottom right corner of your screen!)

Fixed Box

5. Sticky

Toggles between relative and fixed depending on the scroll position. Scroll inside the box below to see it stick to the top.

Sticky Box
